Setup guide

Offline, on the same Wi-Fi or hotspot

  • On one computer run npm start. It prints an https:// address and a QR code.
  • Open that address on every phone and laptop. Accept the certificate warning once (Advanced, then Proceed).
  • Use the same Room ID on all devices, or tap Invite.
  • Tap Connect unit and allow the microphone.

Online

  • Deploy the same server to a Node host and open its https:// address on every device. Nothing else changes.

Talking

  • You only hear units on the same channel (01 to 10).
  • A unit marked LINKING has not finished connecting. If it stays that way, the router may block devices from talking to each other.
  • Use headphones to avoid feedback. Keep the screen on and the page open.
